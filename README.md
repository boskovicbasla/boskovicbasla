### What I build

- **[Ortix Browser](https://systembionic.com/ortix)**: a native macOS browser on WebKit, written in Swift, SwiftUI and AppKit. About 300K lines of Swift, guarded by 3,668 automated tests. No. 1 on MacNative, Product Hunt "UI of the Week", and [selected for Setapp by MacPaw](https://setapp.com/apps/ortix).
- **EVVE**: the on-device AI assistant inside Ortix. Voice, page vision and browser tools on a native Swift/MLX runtime, with permission checks and receipts for every action.
- **[Xified](https://systembionic.com/xified)**: a personal dashboard for iPhone, iPad and Apple Watch (SwiftUI, Core Data, CloudKit, StoreKit).
- **SystemBionic platform**: the website and production backend in Next.js, TypeScript and PostgreSQL, with billing, licensing, an admin hub and health-gated releases.
- **[TheMetalNet](https://themetalnet.com)**: a 3D music-discovery platform over 62,000 bands, built as lead engineer for Solaris Endeavors.
